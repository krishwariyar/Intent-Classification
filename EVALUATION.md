The recorded errors show a strong default-to-ENTY pattern, particularly for DESC and NUM questions. This reflects the limits of predefined wording rules, not a performance result from a trained model.

## Reproduce

Install `requirements.txt`, place the correct licensed test data at `data/raw/trec-test-par.parquet`, then run:

```bash
python scripts/evaluate_rules.py --test data/raw/trec-test-par.parquet
```

The script writes class-level metrics, macro averages, subgroup counts/accuracy, a JSON summary, and a confusion matrix under `outputs/generated/`.

## Optional trained baseline

The repository also contains `scripts/train_baseline.py`, which trains TF-IDF plus Logistic Regression on the training split and evaluates the held-out test split. This is an **experimental baseline only** and is not connected to the current website. Its metrics must be generated by running the script; they are not assumed or pre-filled here.
